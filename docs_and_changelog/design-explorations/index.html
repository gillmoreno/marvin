Marvin · three design directions

Clickable HTML prototypes. Each one covers sign-in / room picker, the room (desktop), settings, and a trimmed mobile version. Use the small toolbar inside each prototype to switch screens, toggle the phone frame and cycle Marvin's state.

A · dark · instrument

Control Room

Mission-control precision: monospace readouts, hairline rules, an oscilloscope line as the room's heartbeat. One hot accent for what is live.

 B · light · typographic

Editorial

The room as a live, well-typeset document: transcript and turns read like prose, timestamps in the margin, voice rendered as ink.

 C · mid-dark · luminous

Signal

The voice is the interface: one living signal element that breathes, works and waits, passing its light to whoever speaks. Soft glass, fine grain.
