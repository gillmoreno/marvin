# Themes (removed)

Marvin used to support built-in and machine-written themes. That system was
removed on 2026-09-15 in favor of one maintained **Workspace** design.

There is no Appearance setting, theme API, or `MARVIN_THEME` override.
Existing `<state_dir>/themes` folders are ignored and may be deleted by the
machine owner. Voice-presence drawings remain part of the fixed interface.

The original design is preserved in git history and the dated changelog.
